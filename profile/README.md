# Project Overview

Affinity Photo is professional image editing and photo manipulation software designed for photographers, designers, digital artists, and creative professionals.

It provides tools for RAW development, retouching, compositing, layer-based editing, masking, color correction, selections, filters, and high-resolution creative workflows.

# Photo Editing

Affinity Photo provides a non-destructive workflow for enhancing and modifying photographs.

Common tasks include:

- Exposure correction
- White balance
- Contrast adjustments
- Cropping and resizing
- Sharpening
- Noise reduction
- Skin retouching
- Object removal
- Background editing
- Creative effects

Layers and masks allow individual parts of an image to be edited independently.

---

# RAW Development

RAW development tools provide control over image data captured directly by compatible cameras.

Typical adjustments include:

- Exposure
- Highlights and shadows
- White balance
- Lens corrections
- Noise reduction
- Detail enhancement
- Color adjustments
- Tone controls

RAW processing can be used as the first stage before additional editing and retouching.

---

# Layers & Compositing

Affinity Photo supports complex multi-layer compositions for photography, graphics, and digital artwork.

Users can combine:

- Pixel layers
- Adjustment layers
- Masks
- Text
- Shapes
- Blend modes
- Filters
- Multiple photographs

This makes the application suitable for both traditional photo editing and advanced image compositing.

---

Retouching and color tools can be used for portraits, products, landscapes, advertising images, and creative projects.

Common workflows include:

- Healing

- Frequency separation

- HSL adjustments

- Levels
- Selective color

# Performance

Affinity Photo performance depends on image resolution, layer count, filters, RAW processing, available RAM, GPU capabilities, and storage speed.

Fast SSD storage and sufficient memory can improve responsiveness when working with large photographs and complex compositions.

---

# Troubleshooting

If Affinity Photo becomes slow or unstable, review document size, layer count, available memory, graphics configuration, live filters, and background applications.

For import or export issues, verify the image format, color profile, document settings, available storage, and destination permissions.

Maintain independent backups of important source images and project files.
